# Лаборатори 7 — Exploratory Testing (SBTM)

## Оюутны мэдээлэл
- **Нэр:** Баттөмөр
- **Оюутны код:** B242270025
- **Үйлдлийн систем:** Ubuntu Linux
- **Node.js хувилбар:** v22.22.1
- **Хөтөч:** Google Chrome 154.0.8037.97

## Төслийн тухай
Энэхүү лабораторийн ажлаар уншлагын жагсаалтын аппликейшнд Exploratory Testing буюу хайгуулын тест хийж, илэрсэн алдаануудыг тайлагнав.

## Тестийн дүгнэлт
1. Тестийн үеэр уншлагын жагсаалтын аппын ном нэмэх, хайх болон API-ийн оролтын шалгалтыг туршсан.
2. Бүх талбарыг хоосон үлдээхэд ном нэмэгдэж байгааг илрүүлсэн.
3. Оролтын хязгаар шалгах үед 999 гэсэн онтой номыг систем зөвшөөрч байгааг олж тогтоосон.
4. Ижил гарчиг, ижил зохиогчтой номыг дахин нэмэх боломжтой байв.
5. API шалгалтаар буруу JSON илгээхэд хүлээгдсэн HTTP 400-ийн оронд HTTP 200 хариу ирсэн.
6. Хайлтын талбарт жижиг үсгээр бичиж хайлт хийхэд үр дүн гарч байгааг шалгасан.
7. Илэрсэн асуудлуудыг тус тусад нь алдааны тайлан болгон баримтжуулж, API-ийн хариуг текст нотолгоонд хадгалсан.
8. Дараагийн тестийн үеэр урт текст, устгах үйлдэл, нийт номын тоолуур болон интерфэйсийн мессежүүдийг нэмж шалгах шаардлагатай.

- `screenshots/` — дэлгэцийн зургууд

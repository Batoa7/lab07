# Лаборатори 7 — Exploratory Testing (SBTM)

## Оюутны мэдээлэл
- **Нэр:** Баттөмөр
- **Оюутны код:** B242270025
- **Үйлдлийн систем:** Ubuntu Linux
- **Node.js хувилбар:** v22.22.1
- **Хөтөч:** Google Chrome

## Төслийн тухай
Энэхүү лабораторийн ажлаар уншлагын жагсаалтын аппликейшнд Exploratory Testing буюу хайгуулын тест хийж, илэрсэн алдаануудыг тайлагнав.

## Тестийн дүгнэлт
Тестийн үеэр ном нэмэх, хайх болон оролтын утгуудыг шалгав. Зөв утгатай ном нэмэхэд амжилттай нэмэгдэж байгааг шалгасан. Заавал бөглөх талбарууд хоосон байхад ном нэмэгдэж байгааг илрүүлсэн. Мөн зөвшөөрөгдсөн хязгаараас гадуур он оруулахад аппликейшн зөвшөөрч байв. Ижил нэртэй, ижил зохиогчтой номыг давхар нэмэх боломжтой байгааг олж тогтоосон. Хайлтын талбарт жижиг үсгээр бичиж хайлт хийхэд үр дүн гарч байгааг шалгасан. Буруу JSON өгөгдлийг API руу илгээхэд хүлээгдсэн HTTP 400-ийн оронд HTTP 200 хариу ирсэн. Илэрсэн асуудлуудыг тус тусад нь алдааны тайланд бичиж, API тестийн гаралтыг нотолгоо болгон хадгалсан. Цаашид хэрэглэгчийн интерфэйс, урт текст, устгах үйлдэл болон нийт номын тоолуурыг нэмэлтээр шалгах шаардлагатай.

## Файлууд
- `charter.md` — тестийн төлөвлөгөө
- `session-report.md` — тестийн тэмдэглэл, тайлан
- `bugs/` — алдааны тайлангууд
- `evidence/` — тестийн нотолгоо
- `screenshots/` — дэлгэцийн зургууд
